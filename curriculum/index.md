# Quantum Visual

Quantum physics from the atom up, for grades 11–12, with interactive 3D visuals, charts, questions and Python labs.

The course runs 8 modules (0–7), about 44 lessons. It assumes algebra and basic trigonometry; light calculus appears only in Module 7.

## Every lesson has six parts

1. **Concept** — one idea, under 600 words, at most one key formula.
2. **3D visual** — an interactive scene with sliders and toggles.
3. **Graph or chart** — the idea as numbers.
4. **Check questions** — 3 conceptual, 3 numerical, worked answers hidden behind a reveal.
5. **Python lab** — compute or plot the idea yourself.
6. **Newton vs quantum** — what classical physics predicts, what actually happens, and when Newton is still good enough.

## Teaching approach

Follow the history where it helps (Thomson → Rutherford → Bohr → Schrödinger), because each model fixes a failure of the last. Each module ends with a "what this model gets wrong" note that motivates the next one.

**Difficulty tags:** [Core] all students · [Extension] JEE / AP 5 level · [Challenge] olympiad or early university.
