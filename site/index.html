Every lesson works the same way

Read one idea
A short explanation with at most one key formula, in plain language.
Play with it
A live simulation beside the text: fire photons, build atoms, split beams.
Run experiments
Tasks that tick themselves when you find something, or check the value you measured.
Check yourself
Questions with instant feedback and a worked explanation for every answer.
Compare with Newton
What classical physics predicts, what actually happens, and where the two agree.
Code it in Python
A notebook that opens in Google Colab, so you need nothing installed.

    For teachers

    Every simulation runs in the browser with nothing to install, so it works on school laptops, tablets and a projector. Progress is saved only in each student's own browser; there are no accounts.

    The lesson text, question banks and Python notebooks are plain files on GitHub. Copy them, adapt them to your syllabus, or send a correction.
